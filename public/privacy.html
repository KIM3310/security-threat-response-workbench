Privacy

Security Threat Response Workbench's public site and demo use synthetic incident exercise data. Do not submit real incidents, credentials, secrets, customer logs, regulated data, or personal data through public links or demo inputs.

The public resource landing may be reviewed for basic traffic, search, security, and advertising readiness signals. Any private exercise, analytics, payment, upload, support, or customer-data workflow requires owner-approved privacy terms, retention rules, processor review, and a private contact path before data is collected.

For repository support and privacy requests, use the repository support instructions without posting personal data in a public issue.
